# TalkingHeadBench

The TalkingHeadBench project website accompanies a benchmark for detecting talking-head deepfakes. The site presents real and generated video samples, evaluation protocols for shifts in identity and generator, and benchmark results.

[Project website](https://anaxqx.github.io/talkingheadbench.github.io/) · [Paper](https://arxiv.org/abs/2505.24866) · [Dataset and splits](https://huggingface.co/datasets/luchaoqi/TalkingHeadBench)

The website template was adapted from [Nerfies](https://nerfies.github.io/) under the license below.
